# Workbench × Simulation: explicit handoff and light appearance

Architects and students need to know which project conditions and model version produced a study before using it in a review. This change uses the current production shared-condition, automatic EPW and unified-study implementations; it does not introduce a second weather service or calculation engine.

- Workbench shows a read-only Site card and a persistent baseline summary. The review includes coordinates, IANA time zone, actual EPW identity/source, building type, floors, north and shared defaults. Missing weather and example locations stay explicit. Confirmation is invalidated by a relevant baseline change.
- Site editing has a dedicated editor. Cancel restores the imported baseline, including terrain/weather changes made during the editing session. Existing site geometry editing remains available separately. A building-type label does not invent a derived occupancy schedule.
- The geometry badge reuses native model validation and study-readiness checks. Errors disable sending; referenced native objects can be located. Closed-room semantics are required for indoor studies; a massing-only project can still use solar studies. Mesh manifold checks and engineering compliance are not claimed.
- Send flushes the active model, reviews a Handoff Summary and only saves/opens Simulation after confirmation. An immutable record retains model version, conditions, climate identity, validation scope and timestamp. A run receives the matching handoff without rewriting previous results.
- Simulation displays its input receipt, climate file/source, global-setting editor link and stale-input warning. Named configurations retain study-specific settings. Results identifies Workbench versus simulation assumptions and compares two actual saved runs, including runs on the same model version; the pair can be exported as JSON.
- Existing plan/3D result overlays, legends, point inspection, object hierarchy, editing history and view presets are reused. No separate result canvas or rendering-based performance claim is added. Sun Hours starts with a reviewable 09:00–15:00 window.
- Interface appearance is fixed to light. Mode switches, system preference detection, stored preference readers, dark tokens and dark catalogue-image variants are removed. The standalone homepage scene is rebuilt from the light-only source. Weather analysis for night ventilation and dark physical materials remain meaningful model content.

Local verification passed immutable-history/confirmation, light-only, study-evidence and structural workflow checks. Browser checks exercised Sun Hours handoff, actual calculations at 09:00–15:00 and 10:00–14:00, named configuration saving, same-version result comparison, assumptions and Site cancellation. The JSON export action was exercised; downloaded file contents were not independently verified. Playwright laptop/shared-condition/editing regressions are configured for CI and have not run for this branch. Publication status must be checked separately; local verification is not evidence of deployment.
