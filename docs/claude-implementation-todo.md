## 产品硬约束

- 主流程为 Site analysis → Plan Studio → Simulation → Rendering → Boards；允许独立工具和导入模型直接分析，不强迫逐步完成。
- Simulation 顶层只有建筑分析、室内分析、表格类型。Workbench 是辅助工作区，复用现有 Workspace/Plan Studio。
- Simple/Advanced 是 UI 模式；单项覆写两者都可用，切换不丢数据、不自动改精度。
- 地址可启动气候研究；建筑、室内、结构分别检查其必要模型与专业输入。
- 保留既有工具、路由、模型、历史结果、资源和参考引擎路径；退役入口须有明确映射与兼容策略。
- 当前 EPW 自动匹配/改站/上传、A/B、PDF/HTML/CSV/JSON、Workbench 已有基础，先检查再复用。
- 每个结果关联固定输入、模型/楼层、天气、设置、方法/引擎版本和生成时间。改变相关输入要说明旧结果适用状态。
- 不把浏览器估算改名为 Radiance/EnergyPlus/CFD，不把渲染当性能验证，不把筛查标为认证。
- 桌面优先，覆盖手机基本导航/查看/导出回归，暂不扩展手机专项建模。
