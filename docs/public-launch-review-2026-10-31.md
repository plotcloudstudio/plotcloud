# PlotCloud 发布检查（2026-10-31）

用户目标：建筑师或建筑学生在设计评审前，用同一项目的方案 A/B 实际模拟结果生成可追溯报告。主要交付是报告及其依据。

## 本次核查的事实

- 网站当前由 GitHub Pages 提供静态文件。核心浏览器模拟及本地报告不需要付费 AI 接口。
- 线上 Home、Pricing、About、Blog、Resources、Log in、Get started 已共享导航。公开页字体为 Inter；抽查未出现水平溢出。Legal 原来仍使用旧导航，此次接入共同外壳并修正政策标题/正文排版。
- 移除对外 Prototype、Beta、Testing phase 阶段标签。保留示意图、估算、方法限制和未计算状态；内部存储键、权限协议、结果来源标识保持兼容。
- 后端只读探测：Auth 可连接；cloud_projects 和会员 RPC 报告 PGRST 缺失/初始化错误。尚未验收真实账户隔离、跨设备同步或会员授予。
- Pricing/登录/条款所述免费范围仍与 FREE_STUDIES（全部模拟）不同；Resources 页面/价格表也有免费范围不一致。发布收费前必须确定并统一，不能仅修改金额或隐藏限制。
- 当前付款流程为邮件确认、e-transfer、人工开通，尚非自动订阅。
- 当前登录页未提供密码找回完成流程。需要补齐邮件、重设密码、失效链接与重新登录验收。
- 室内 AI 渲染服务仍是单实例操作员服务；不具备面向付费用户的持久队列和完整计费机制。不能把它当成已部署的生产服务。

## 发布前的最短验收流程

1. 确定正式域名和托管；保留旧链接重定向、导出原浏览器项目后再迁移。更换域名不会迁移旧域名的本地存储。
2. 初始化 Supabase 项目、版本、账户和会员表及行级权限；注册两个独立用户验证数据隔离。
3. 配置正式域名的 Auth 回调和自定义 SMTP；验证注册、确认、登录、找回、退出和重新登录。
4. 导入真实模型 → 保存 A → 运行并保存模拟 → 复制并修改 B → 同条件运行 → 比较 → 下载并检查 PDF/CSV。
5. 改变场地、天气、模型或设置后，旧结果必须保留来源和适用状态。缺少成对结果不能显示虚构改善百分比。
6. 确认收费范围、总价、开通时间与退款说明一致；核对会员到期以及未登录用户的实际权限。
7. 核对公开页、工作台、报告及政策页面的字体、按钮、表单、间距、错误/空状态；桌面优先，窄屏保证可操作。

## 成本建议（USD，税前，额度内；不含人工）

- 最低起步：Cloudflare 静态托管免费 + Supabase Free + Resend Free + 普通 .com 域名，约 12–15/年。使用服务商免费子域名可省域名费用，但正式品牌建议独立域名。
- 更稳妥的小规模收费运营：Supabase Pro 起价 25/月，另加域名。一个基础项目预计固定费用约 312–315/年；超额、额外计算、AI、地图付费和收款费用另算。
- GitHub Pages 官方不允许把其用作商业 SaaS 的免费托管；商业发布前迁出。Cloudflare 推荐新项目使用 Workers，现有纯静态代码可按静态资产部署。
- Supabase 默认邮件发件服务只适合预授权团队地址且额度很小，不能作为公开注册邮件方案。自定义 SMTP 是必须配置，不等于必须购买付费套餐。
- 无需为让访客使用浏览器模拟而购买 Figma、Framer、Webflow 或 AI 聊天会员。开发订阅与网站运行成本分开。

## 产品优先级

- 核心：稳定完成真实 A/B 比较和报告；清楚显示结果来源、条件差异和缺失依据；保存和导出可靠。
- 辅助：首屏提供完整报告样例、统一公开页和政策页；追踪开始项目、计算完成、成功导出报告三个关键转化。
- 延后：大型资源商城、更多缺乏验收的分析入口、自动 AI 解读、公开付费渲染及多人实时协作。
- 移出主要导航：旧版主页入口与重复的产品介绍。保留兼容路由和原数据。
