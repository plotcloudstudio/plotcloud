AI rendering requires a secure external image-generation endpoint. GitHub Pages cannot execute a model or keep API secrets. Do not paste API keys into this page.

Endpoint must support browser CORS and accept the documented JSON request. Endpoint is not saved.Use only an access token issued by your rendering service. Never enter a model provider API key. This field stays in memory and is excluded from exports and image records.
Integration contract

POST JSON: interior_workflow (versioned source, target and reference bindings), source_image (data URL), reference_images (data URL array), prompt, negative_prompt, scene, style, preserve_geometry, structure_strength (0–1), variation_strength (0–1), material_prompt, edit_mode, mask_image (PNG data URL or null; WHITE region = modify). The endpoint must actually implement geometry control and inpainting for these settings to affect the result. Return JSON with image_url (HTTPS) or image_base64 (PNG/JPEG base64) or image_data_url. Do not embed service secrets in browser code. Server must enforce authentication, usage limits, input validation and safe output.
