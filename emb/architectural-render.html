03 / Render connection

AI rendering requires a secure external image-generation endpoint. GitHub Pages cannot execute a model or keep API secrets. Do not paste API keys into this page.

Endpoint must support browser CORS and accept the documented JSON request. Endpoint is not saved.
Integration contract

POST JSON: source_image (data URL), reference_images (data URL array), prompt, negative_prompt, scene, style, preserve_geometry. Return JSON with image_url (HTTPS) or image_base64 (PNG/JPEG base64) or image_data_url. Do not embed service secrets in browser code. Server should enforce authentication, limits, and safe output.
