One Workspace: Plan Studio inside the project

Design preview for review. The canvas is the real, current Plan Studio; nothing in it has been rebuilt.

  1. Everything in Plan Studio stays: parametric furniture, walls and solid walls, lights, the yellow/green move arrows, blue rotate, explode, clearance, the draggable toolbar, Tab to cycle the nearest object, 2D plan and elevations, 3D with walkthrough.
  2. Versions: Plan Studio's own Versions card (right panel) is the only version list, with its 2D compare. In the full version each saved version also goes to the project for Simulations and Results.
  3. Saved views stay in the left “Views” tab. Rendering is removed for now.
  4. Removed from Plan Studio's top bar: its own logo, Open model, New model and Send to Simulation. The project, site and “Simulate →” live in the bar above.
  5. Site model (planned): after choosing an address in Account, terrain and nearby buildings come in as an editable, lockable Site layer and can be exported with the model. Not connected in this preview.
  6. From the earlier Workspace (planned, kept): .obj/.stl/.glb import as context, room finishes for acoustics, and the wireframe view in simulations.
